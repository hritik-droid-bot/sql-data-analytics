# SQL Data Analytics

My SQL learning journey for Data Analytics.

## Progress

This repository documents my SQL practice from fundamentals to analytical SQL.

### Topics covered

- SELECT, FROM, WHERE
- AND, OR, BETWEEN, IN, LIKE
- ORDER BY, LIMIT, DISTINCT
- Aggregate functions
- GROUP BY and HAVING
- CASE, NULL handling and aliases
- Text and numeric functions
- JOINs
- Subqueries
- CTEs
- Window Functions
- ROW_NUMBER, RANK, DENSE_RANK
- LAG and LEAD
- FIRST_VALUE, LAST_VALUE, NTH_VALUE
- Window frames
- Difference and percentage-change analysis

## Goal

Build strong, practical SQL skills for Data Analytics and apply them to real-world datasets and portfolio projects.
